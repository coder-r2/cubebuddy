The cube's actual state is right; only the picture is wrong. That's why "Find next F2L pair" sometimes showed the pair in the wrong place.

  - The 3D view only updates its snapshot when the cube state changes, so it keeps the first animation frame.

  - The default 3x3 view doesn't keep a snapshot, which is why only this view is affected.
